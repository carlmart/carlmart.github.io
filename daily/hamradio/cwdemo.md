# CALLING CQ
First make sure the frequency is clear.
QRL = is freq clear?
QRZ = who's calling? 
```
DAV3 Calling CQ <--- CQ CQ CQ DE DAV3 DAV3 PSE K
     BEN2 ANSWERS ---> DAV3 de BEN2 UR 5NN 5NN NC BK

DAV3 RETURNS <--- BEN2 DE DAV3  GE ES TNX FER CALL
     ---> UR RST 5NN 5NN 
     ---> NAME IS DAVE DAVE 
     ---> QTH SD  BK

     BEN2 ENDS ---> BEN2 DE DAV3 
               ---> BK TU ES  73 DAV3 SK  ... _._
```
